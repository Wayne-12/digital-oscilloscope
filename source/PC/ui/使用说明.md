## 启动与连接

1. 保持 OUTA→SMA→ADC IN、共地与既有接线。开发板上电等待 DONE，SW0 OFF；打开模块外部 5 V，稳定后再将 SW0 OFF→ON。
2. 双击根目录 `启动示波器界面.cmd`，默认选择硬件串口、COM12、921600。点击“连接设备”，顶部显示实际固件与能力；正常 QSPI 上电不需重新烧录。
3. 已保存的 DDS 设置是待应用值。若设备输出关闭，选择正弦 100 kHz、10% 数字幅度、相位/偏移 0、勾选启用后点击“应用 DDS 配置”。数字幅度不是保证电压；旋钮决定模拟增益。
4. RUN 连续请求快照，STOP 冻结，SINGLE 一次后保持。修改硬件配置时先 STOP 并等待配置确认；导出文件也在 STOP 后进行。

关机先 SW0 OFF，再关闭模块外部 5 V，最后关闭开发板；插拔接线先全部断电。

## 两种数据源与采集模式

当前正式界面采用美化版布局，右侧通过四个标签切换：

| 标签 | 控件 |
|---|---|
| 采集 | 采样状态、记录与预触发、时基、垂直刻度/中心、Autoscale、采集模式 |
| 触发 | 触发类型及当前类型相关参数、应用触发配置 |
| 输出 | DDS参数、输出启用、任意波形CSV下载 |
| 工具 | 光标、设备状态及日志 |

| 数据源 | 实际行为 |
|---|---|
| 演示模式 | PC 软件生成，无需设备；校准与波形均标注演示 |
| 硬件串口 | 读取完整 16384 点真实冻结帧 |

新版 AUTO 无触发约 100 ms 后自动触发；NORMAL 等待所选条件，可用 STOP 取消；SINGLE 一次保持。硬件串口按照所选模式与触发条件采集；不再提供独立的联动数据源、短窗口自动读取或正弦拟合曲线。

25 MSPS 与 16384 点固定，完整记录窗 655.36 µs。预触发可设 0～100%，点击“应用记录配置”。水平时基/缩放不改变采样率或记录窗。电压输入可选 mV/V，切换自动换算；触发参数点击“应用触发配置”才下发。

## 四个功能页

| 页面 | 查看与操作 |
|---|---|
| 时域波形 | 原始读回波形、触发位置、整帧饱和样本/连续事件；顶部 Vpp/RMS/频率/占空比，底部最大/最小/均值/周期；时间/电压光标、Autoscale 和撤销 |
| FFT 频谱 | 青色曲线为 PC 当前读回窗口前 1024 点的频谱，窗可选；下方 FPGA 固定取完整冻结帧前 1024 点的 Hann 主峰/H2～H5 摘要。ROI 不足 1024 点时需读取更大选区或返回完整记录查看 PC 频谱 |
| 多分辨率采集 | 勾选板端概览、选 100/200/400/800 桶后采集；STOP 后拖动 ROI 读取同一冻结帧细节，最多 2048 点。PC 缓存最近 16 帧，选择历史会冻结查看 |
| 闭环自检与校准 | 真实自检共 35 帧，零点/九点直流/四档线性/七点频响/谐波/独立验证；结束、失败、取消后恢复配置并回读；通过后可应用相对显示校正 |

整帧饱和定义为原始 ADC 码 0 或 4095，连续区间算一次事件，帧首尾不相连。UI 不显示独立 OTR 报警；波形 CSV 保留原始 OTR，数字触发中的 OTR 功能仍保留。

真实模拟过载验收已完成，依据用户于2026-10-30确认已在老师帮助下完成验证。复测入口 `FPGA/scripts/verify_analog_overload_hardware.py` 继续按每次实际采集结果记录完整原始帧、OTR、计数与配置恢复。历史自动采集结果与最新确认依据见 [模拟异常验收记录](../../docs/verification/analog_overload_20261029.md)。

1024 点 FFT 的 Δf 为 24.414 kHz；低频以足够周期的时域测频为准。无效测量显示“—”。多分辨率 ROI 中的 PC 波形、PC 频谱与 FPGA 摘要的样本区间可能不同，界面底部明确读回窗口与整帧范围。

## DDS 与任意波形

切换右侧“输出”标签：正弦/方波/三角/直流支持频率、数字幅度、相位、中码偏移和启用。直流零偏移对应 DAC 中码 8192。

**频率上限与实测范围分别记录：数字设置仍为0～12.5 MHz，不作下调。** 2026-10-29 在原旋钮、819码峰值（约10%数字幅度）、25 MSPS闭环下完成256帧扫频：正弦、方波、三角波均在10 kHz～12.49 MHz的23个已测频点通过各自基础检查；相对100 kHz的拟合基波幅度位于±3 dB内的已测频点为10 kHz～8 MHz，共17点。8 MHz与9 MHz之间没有确定精确的−3 dB交点，频点间也未逐点验收，因此不能称为连续8 MHz模拟带宽。

正弦基础检查包括采样正弦残差≤10%；方波/三角波仅检查基波存在、频率位置、幅度与重复性，不授予高频形状、边沿、THD或SFDR质量。12.499 MHz受固定记录长度的边界拍频周期限制，只作观察；12.5 MHz属于奈奎斯特边界，零相位正弦/三角可能退化到近中码，不能作为正常输出质量通过点。具体频点、相位、幅度下降和原始证据见 [DDS扫频实测记录](../../docs/verification/dds_sweep_20261029.md)。悬停频率输入框可查看本轮范围说明。

“下载任意波形 CSV…”接收 1024 点单列 `value`（标题可省），每点 [-1,1]。示例在 `PC/waveforms/`。下载停止采集、关闭输出，写非活动表并完成 CRC 和全表读回；成功不自动开启输出。选择“任意波形表”、设置参数并应用后才输出；频率是整表重复频率，25 MHz 相位累加器可能跳点/重复点。断电、复位或重新配置后重新下载。

## 相对闭环校准

步骤结果和校准前后对比表会按内容换行、自动展开全部行；页面随结果长度、窗口大小和字体变化增高。内容超出窗口时使用校准页右侧的统一滚动条查看下方频响图与说明，表格和说明之间不再挤压重叠。

保持旋钮、接线和供电条件不动。可在 RUN 时发起，自检先自动停止并等待接收结束；取消后等待恢复完成。每轮原始码与报告在 `PC/calibration_runs/`，基线和最近结果在 `PC/ui/hardware_calibration_*.json`。

第一次通过建立 DAC＋线缆＋ADC 组合链路参考，以后比较漂移；独立零点与 +512 DAC 码点显示校准前后误差。相对校正只改显示和导出的电压列，保留原始 ADC 码；超出已验证幅度范围不套用。重新连接、换源或手动应用 DDS 后重新自检。旋钮改变后，应固定新条件再决定是否重建基线。该功能不等同于绝对电压校准。

## 外部参考直流电压标定

“闭环自检与校准”页顶部新增“外部参考电压标定…”。当前没有独立电压测量仪器，设备仍为**未完成绝对标定**；不能把 DAC 理论输出、标称 ±5V 或相对校准基线作为绝对参考。原 ADC 模拟量程保持不变。

具备参考仪器后，可用板载 DAC 产生稳定直流，并在 ADC 负载保持连接时，用独立仪器测量 ADC 输入端实际电压。不需要用 DAC 的理论码值推算参考电压。参考仪器必须适用于相应直流档位，并提供该读数下的最大误差界限；未知或填零时不能发布参数。

1. 打开标定窗口，填写参考仪器型号/编号/误差依据和接线、负载、供电、温度或预热条件。窗口可关闭后重新打开，当前程序内的草稿保留；不会自动设置硬件输出。
2. 设置稳定直流，在主窗口完成新的完整 SINGLE，STOP 并等待接收结束。在标定窗口填写同时测得的电压和参考最大误差界限，确认来自独立仪器，再添加当前帧。每个点需要新帧，演示、ROI、数字诊断、OTR、饱和和不稳定输入均拒绝。
3. 先完成至少3个拟合点，覆盖负、近零、正电压；再采至少2个不同电压的验证点，覆盖正负电压且不参与拟合。验证点须位于拟合范围内，并与拟合点分离。标定跨度至少256个ADC码；本轮最多32点。
4. 点击“验证、保存并载入”。线性增益/零点拟合、独立验证点误差及参考误差裕量全部满足填写的点检目标误差限后，才保存参数。默认10mV是可修改的点检目标，**不是设备已达到的精度**。
5. 主窗口勾选“显示应用外部参考直流校正”。与相对校正互斥，不会叠加。设备、固件、采样率和当前记录原始码范围必须匹配；不向实测范围外推，异常帧不应用，重连或换源后需重新勾选。

每轮文件在 `PC/ui/absolute_calibration_runs/<会话>/`，含原始 NPY、SHA256、参考仪器/条件、参考值、系数、适用范围及校正前后误差。载入已有 `calibration.json` 时需保留同目录原始 NPY；程序核验并重算，不直接相信保存的 PASS 字段。更换 ADC 模块或模拟链路、改变原量程或测试条件后需重新标定。关闭整个程序前尚未发布的草稿不会自动成为有效标定文件，已采原始证据保留。

校正影响波形、测量、PC FFT、包络及导出中的显示电压；原始 ADC 码与 FPGA 原始摘要不改。FPGA FFT 摘要幅值仍标注为标称换算。触发设置继续使用原标称量程的电压，界面会明确提示。CSV 同时保存标称/显示电压和校正来源，工程汇总另列显示测量与标定元数据。

该流程完成的是**外部参考直流点检及线性校正**，不自动获得全量程、交流幅值/带宽、温漂或计量溯源资格。参考读数由操作者录入，软件不能验证其是否确由仪器测得；误差裕量也不是完整的测量不确定度预算。详细实现与当前验证边界见 [绝对电压标定记录](../../docs/verification/absolute_voltage_calibration_20261029.md)。
