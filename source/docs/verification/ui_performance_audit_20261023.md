## 已修复的缺陷

1. **刷新重置缩放和 ROI**：新帧不再反复强制设定时域坐标；相同记录布局保留用户拖动的 ROI。修改时基、刻度或显式 Autoscale 仍按操作调整坐标。
2. **隐藏页重复计算与绘制**：页签切换时按需更新，测量和电压不再多次扫描完整记录。
3. **导出冻结及快照混用**：CSV 在后台分批写入，在文件选择框打开前锁定不可变原始快照和校准参数；新帧不会混入正在导出的记录。
4. **保存失败破坏旧 CSV**：在同目录创建临时文件，完整成功后替换目标；失败或取消时清理临时文件，保留原目标。
5. **STOP 后迟到帧覆盖冻结/历史画面**：只接受来源匹配且仍处于本次活动采集状态的硬件帧。
6. **请求无限积压及操作竞争**：请求队列限制为 16 项，状态与捕获请求合并；STOP 使用独立事件，配置等待确认时不能启动新的采集，重复 SINGLE 不会重置正在处理的采集状态。
7. **成功响应缺少语义验证**：检查配置/采集/停止 ACK 的长度和零状态、PING 回显、设备版本、状态字段及完整写入结果。
8. **分包重组校验缺口**：拒绝重复 FIRST、异常标志、错误总长度/偏移、提前或缺失 LAST；保留 CRC、序号、时间戳、采样率和触发索引的一致性检查。
9. **采样数据可被误修改**：Capture 校验维度、数量、整数范围、保留位和元数据，并持有独立只读样本副本。
10. **指纹文件导致异常或污染基线**：限制读取为 1 MB，拒绝非数值、布尔、非有限、越界或负噪声参数；处理编码及深层 JSON 错误；失败前不更新基线。文件错误不再意外停止正常采集。
11. **关闭窗口阻塞**：不在 GUI 线程 wait 等待串口/导出线程；发出退出或取消请求后通过事件循环完成资源释放。
12. **滚动面板误改参数**：未聚焦的数值框与下拉框将滚轮交还面板，减少滚动时误改 DDS、采样或触发参数。
13. **非相干 FFT 误报 THD**：对基波相干性增加时域交越验证；不满足时显示无效 THD，避免把泄漏当作失真。仍是第 2～5 次谐波的 PC 估计。
14. **演示毛刺不可见及边界脉宽误触发**：毛刺放置于实际可选记录中；不把生成区间边界截断的脉冲当成完整脉宽事件。

检查了程序的外部数据入口与文件操作；没有使用 eval、pickle 或动态执行导入的指纹。以上是针对当前源码的缺陷检查和回归，不等同于“保证不存在任何漏洞”。
