## 实现

将12位ADC原始数据和原始OTR输入的首级采样寄存器显式定义为 `raw_iob[11:0]` 与 `otr_iob`，施加 `IOB=TRUE`。输出用直连导出原有采样值，保留原有25 MHz上升沿、时钟使能、同步复位值与7+1周期延迟/时间戳契约，没有插入额外流水级。

构建脚本在综合后核对恰好13个目标寄存器，并在布线后逐个读取LOC、BEL、site_type和IOB属性。必须全部位于ILOGIC输入寄存器站点，SLICE或数量不符均停止。单独输出ADC输入最大延迟与最小延迟报告，同时保持原输入输出延迟和全部时序检查。

候选固件为 `0xA3261027`、能力31，保留已完成的三模式和完整帧饱和统计。用户要求饱和统计实物通过后先不固化，紧接着完成IOB；本轮暂不操作Flash。
