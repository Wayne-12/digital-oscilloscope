# 第五步：纯数字闭环通道

本步连接实际已有 RTL 与数字行为模型，验证组合链路的主要数字现象。它不复现板卡的模拟电压、电流、真实噪声谱、抗混叠滤波器或器件非线性。工具为 Vivado/XSim 2025.2；没有改变临时器件、开发板选项或管脚约束。

## 链路与文件

```text
DDS RTL → AD9767 A 通道双缓冲 → loopback_channel_model
        → AD9226（7 周期 + Tco）→ adc_capture（额外捕获边沿）
        → pack_sample → 仿真记录缓存 → 读回上报及有符号解码
```

新模型位于 `FPGA/sim/models/loopback_channel_model.sv`。记录缓存/读回支架位于 `FPGA/sim/models/sample_record_readout_model.sv`。闭环测试位于 `FPGA/sim/tb/loopback_scenario.sv` 和 `tb_loopback.sv`，均只加入 Simulation Sources。已有 DDS、DAC 模型、ADC 模型和采集 RTL 未改动。

独立黄金模型、轨迹审计、回归和工程入口分别为：

- `FPGA/scripts/generate_loopback_vectors.py`
- `FPGA/scripts/audit_loopback_traces.py`
- `FPGA/scripts/run_loopback_tb.ps1`
- `FPGA/scripts/check_loopback_project.tcl`

所有手写 HDL 统一 `1ns/1ps`、`default_nettype none`。DDS 使用输入时钟下降沿；DAC/ADC/采集使用上升沿；通道使用同一输入时钟下降沿，无组合逻辑产生的 RTL 内部时钟。

## 通道约定

输入 DAC 码为无符号 14 位，先转换为显式有符号 64 位中心码 `x = dac_code - 8192`。输出是有符号 32 位理想 ADC LSB，直接接入 AD9226 模型的 `ideal_sample`，不是模拟电压。

| 参数 | 含义与允许范围 |
|---|---|
| `DELAY_SAMPLES` | 额外整数样本延迟，0..64 |
| `FRACTION_Q16` | 0..65535，对应 [0,1) 个样本的因果线性插值近似 |
| `GAIN_Q16` | 0..262144，即 0..4 倍，默认 16384/65536 = 1/4 |
| `INVERT` | 0 为正极性，1 为增益后取反 |
| `OFFSET_LSB` | 有符号 ADC LSB，-1000000..1000000 |
| `NOISE_LSB` | 0..4096，离散均匀伪随机噪声的峰值，零关闭 |
| `CLIP_ENABLE/LOW/HIGH` | 可选输出上下限，LOW 必须小于 HIGH |
| `LPF_ALPHA_Q16` | 1..65536，一阶低通系数；65536 为直通 |
| `EVEN_Q16/ODD_Q16` | -65536..65536，二次/三次多项式扰动系数 |
| `noise_seed` | 32 位伪随机种子，0 映射为 1，验证复位时加载 |
| `force_otr_enable/value` | 按通道输出/ADC 输入事务注入 OTR，和同拍通道结果一起寄存 |

令 `D=DELAY_SAMPLES`，`f=FRACTION_Q16/65536`。在通道 tick n，分数延迟输出取最近整数的 `(1-f)*x[n-D] + f*x[n-D-1]`。这是一阶插值，会产生相应的幅频影响，不是精确的模拟分数延迟滤波器。

随后依次执行：

1. 二次项 `round(EVEN_Q16*x*x / (65536*8192))` 与三次项 `round(ODD_Q16*x*x*x / (65536*8192^2))` 加回信号。
2. Q16 增益、极性、有符号直流偏置与伪随机噪声。
3. 一阶低通。内部状态保留 Q16 ADC LSB：`state += round((input*65536-state)*alpha/65536)`，输出再除以 65536。
4. 可选通道削顶，最后检查输出可由 signed32 表达。

所有除法按最近整数、恰好半数远离零。所有乘法、累加、插值和滤波中间值均显式 signed64；参数范围使乘积保持在该范围内。二/三次多项式会同时改变基波、直流及谐波，不等价于只增加一条纯谐波。

噪声使用可复现 xorshift32，映射到 `[-NOISE_LSB,+NOISE_LSB]` 的离散均匀值，作为近似白噪声。回归检查范围、均值与逐样本序列，不声称验证了真实模拟白噪声谱。

`rst` 是高有效、下降沿同步的验证复位，清空历史、滤波器、有效位、输出及随机状态。DAC 尚无有效输出时也同步清空，填充不足时输出零且 `sample_valid=0`。该有效位用于验证追踪；ADC 仍按真实连续时钟采样，预热零样本保留在记录中，统计时明确排除预热段。

## 时间与 OTR

本步 DAC 与 ADC 均为 25 MHz 共同时钟。AD9767 在上升沿更新 DAC 锁存器；通道在后续下降沿处理该稳定输出，供再下一个上升沿的 ADC 使用。因此，即使 D=0，仍有明确的路由采样延迟；黄金模型按每个边沿独立推进，不把该延迟合并进 ADC 的 7 周期。

对进入 ADC 的样本 n，原始码/OTR 在 n+7 的上升沿后 Tco 出现，`adc_capture` 在 n+8 锁存。Tco=3.5 ns 与 7 ns 两端均测试。上升沿后、Tco 到来前断言 ADC 总线仍为上一拍值，再核对 Tco 后的原始码、OTR 和模型有效位。采集时间戳明确指向 ADC 输入样本 n。

通道自身削顶与 ADC 过量程分别处理：通道在 ±1000 ADC LSB 限幅时，ADC 仍在量程内，OTR 应为 0；过驱配置使 ADC 输入超出 [-2048,2047]，AD9226 自动饱和并置 OTR。正常未超量程配置的 OTR 全部为 0。强制 OTR 支持高电平脉冲、连续高电平及强制低电平；它按 ADC 输入事务注入，与对应样本经过同一 ADC/采集流水线。

## 存储和上报验收范围

采集结果使用真实 `scope_pkg::pack_sample`，记录格式仍为 `{OTR,3'b000,raw_code[11:0]}`。仿真缓存写入该 16 位字，读回后使用现有 RTL 解码函数得到有符号值；scoreboard 则独立按位拼接，并用 `2047-raw` 计算预期值，逐项核对原始码、保留位、OTR、时间戳与解码结果。

缓存在采集寄存器后的下一个上升沿写入。测试先禁止采集、排空寄存级，再逐地址读回，要求总数相等且时间戳连续，防止 OTR 丢失或错位。时间戳使用验证侧旁带数组，不改变 16 位样本字或最终存储布局。

例如强制 OTR 配置的中码用例中，ADC 输入事务 17 为零值、OTR=1：原始码为 2047，采集发生在事务边沿 25，缓存写入在边沿 26，读回地址/时间戳为 17，16 位字为 `0x87FF`，解码结果为 0。

模型记录缓存用于验证原始字和 OTR 对齐；当前板级捕获使用 16384 点 BRAM。模型缓存容量不能作为硬件存储能力证据。

## 测试矩阵和判据

13 种通道配置分别覆盖：默认 1/4 增益、反相、3.25 样本延迟、1/8 增益及 +123 偏置、±3 LSB 噪声、±1000 削顶、alpha=1/8 低通、二次扰动、三次扰动、1/2 增益过驱、组合扰动、1.75 样本延迟及 OTR 强制注入、4+(65535/65536) 样本延迟。每种均覆盖 Tco 两个端点，共 26 个场景。

每个场景依次测试中码、正负直流、10 kHz/100 kHz/1 MHz 正弦、7 档 DDS 幅度与 2048 拍随机配置；基线场景另外运行 1 kHz 长记录。默认两种子分别为 20261020、42，每种子完成 366 个子用例。黄金模型用 Python 独立整数与时间线计算，不读取 RTL ROM 或调用 DUT 函数。

基线幅度验收结果：

| DDS 峰值幅度 | 0 | 512 | 1024 | 2048 | 4096 | 6000 | 7500 |
|---|---:|---:|---:|---:|---:|---:|---:|
| ADC 峰峰值 | 0 | 256 | 512 | 1024 | 2048 | 3000 | 3750 |

要求以上峰峰值严格递增。正向/反向配置全部对应样本必须互为相反数，正偏置直流分别解码为 +512/-512，负偏置则相反。正常配置 OTR=0，过驱自动 OTR 与强制 OTR 的记录和读回必须逐样本一致。

独立 CSV 审计还检查每例的范围、总和、均值、平方和、OTR 数量、字和、时间戳连续性、记录读回及长记录长度。相同基波分别拟合常量、sin、cos 三参数，核对低通和分数插值的幅频响应；整周期窗口检查二/三次谐波确实增加。幅频响应绝对误差限为 0.01。

1 kHz 用例运行 100256 个 ADC 时钟，捕获 100248 条，剔除前 128 条后仍有 100120 条，用于覆盖至少四个完整周期。普通 16K 短记录没有被要求包含 1 kHz 完整周期。

## 重跑与报告

```powershell
& 'D:\示波器\FPGA\scripts\run_loopback_tb.ps1' -Project
& 'D:\示波器\FPGA\scripts\run_loopback_tb.ps1' -Seeds 123,456 -Project
```

每次从新的 ASCII TEMP 目录编译。原始向量与黄金结果分别存入 `sim/vectors/loopback/<run>/`、`sim/expected/loopback/<run>/`。报告存入 `FPGA/reports/loopback/<run>/`，包含编译/展开/运行日志、命令、源码 SHA256、每种子 52 份 CSV、独立测量审计及重放哈希。

每种子检查 1,258,816 个闭环周期，采集并读回 1,255,888 条记录。首种子重放与原生工程各要求 52 份 CSV 哈希一致；30 ms watchdog 和终止 PASS 双重限制运行。原生工程仿真顶层为 `tb_loopback`，设计顶层保留 `scope_hw_top`，本步未接入板级 DDS 配置或引脚。

本机原生 Vivado 启动需要用户 AppData/TclStore 写权限。模型仍只在 Simulation Sources，Design Sources 依赖审计要求保持独立；工程初始化的全局板库提示与 HDL 编译/展开/运行诊断分开保留，HDL 验收要求零警告、零断言失败。

工程内仿真在启动前复用第一步的生成目录清理规则：先验证绝对目标恰为当前工程的 `scope_smoke.sim`、没有重解析点，再删除这一已知生成目录，保留 XPR/IP/RTL/测试源文件。这样避免旧顶层留下的 package 依赖 SDB 缓存；原生日志还必须包含参数包、ADC、采集和闭环源文件的重新编译记录。
