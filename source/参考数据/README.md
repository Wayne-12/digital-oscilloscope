# 参考数据（模型按标定参数生成）

> 本目录为模型按 `校正参数.json` 的标定系数、25 MSPS / 16384 点和端轨 0/4095 生成的参考帧，
> 用于报告排版、绘图、软件测试和结果对照。
> 每帧头部保留 `synthetic,true` 与 `mode: model-reference`，据此可与硬件采集帧（`source=硬件 UART`）区分。

## 生成口径

| 项目 | 取值 |
|---|---|
| 采样率 / 点数 | 25 MSPS / 16384 点 |
| 标定换算 | V = -0.0024016158055761 × raw + 4.9327948749881605 |
| 端轨 | raw 钳位 0 / 4095，OTR 取端轨掩码（otr_nonrail=0） |
| 噪声 | σ = 0.8 码 |
| 正弦频率 | 100 kHz |
| 触发索引 | 按场景：0 / 8192 / 16383 |

## 怎么用

- 画图：`pandas.read_csv(..., comment="#")`，用 `time_from_trigger_s` 和 `display_voltage_v`；
  `raw_code_12bit` / `otr` 用于端轨与 OTR 对照。
- 填表：直接引用 `汇总.csv`；报告里图片标题写“**参考波形（模型生成）**”。
- 对照：硬件采到对应场景后，把采集帧与本目录参考帧叠图，差异（阈值、噪声、饱和计数）才是真正结论。

## 怎么替换

1. 硬件采集帧的 `source` 字段是 `硬件 UART`；本目录是 `参考数据_模型生成`，不要混用。
2. 用采集文件替换 `01`～`09` 中对应场景，重跑 `汇总.csv` 和记录表。
3. 报告定稿前，正文、图题、表头标注为参考数据（模型生成），与硬件采集帧分列。
