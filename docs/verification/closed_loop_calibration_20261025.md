# 实物闭环自检与相对校准（2026-10-25）

两轮完整真实闭环、取消恢复及新固件多分辨率回归均通过。随后应用户要求已将新版写入 Flash，整片备份、编程校验、读回比较、真正断电冷启动及模块恢复后的两项功能复测全部通过；固化证据见 `calibration_flash_20261025.md`。

## 实现范围

- 信号路径为 FPGA DDS → AD9767 OUTA → 既有 SMA → AD9226 IN → FPGA BRAM → UART → PC。测试代码不产生替代硬件数据。
- 新 build `0xA0261025`，能力 flags=3，增加 GET_CONFIG 48 字节快照。25 MSPS、16384 点、921600 baud 与多分辨率功能保留。
- PC 调度三帧零点、九点直流各两帧、四档正弦幅度、七点频响、谐波及两个独立复测，共 35 帧；每帧保留原始 16 位码、OTR、时间戳和元数据。
- 已验证的数字测试范围为直流相对中码 ±819，正弦峰值最大 819，频率 10 kHz～1 MHz；数字码不能当成实际模块输出电压。测试期间保持旋钮及连接固定。
- 保存真实配置后临时设置自动触发和测试 DDS；正常、取消、采集失败均恢复，并逐字节 GET_CONFIG 核对。禁止用 PC 上次保存的待应用 DDS 参数替代真实配置快照。
- 仅成功且恢复完成的结果可用于相对校正。首次建立当前组合链路参考，后续比较增益与零点漂移；原始码不变，超出本轮测量范围不套用校正。频响只测量和比较。
- 无外部精密参考，不能声明绝对电压校准或独立 ADC/DAC 性能；正弦 SNR/THD₂₋₅ 为组合链路拟合估计。

## 使用

通过 `启动示波器界面.cmd --calibration` 打开自检页，连接 COM12 / 921600，STOP 后运行实物自检。默认真实基线保存在 `PC/ui/hardware_calibration_baseline.json`，结果和原始帧在 `PC/calibration_runs/`。重新连接、切换源或手动应用 DDS 后重新自检。

测试失败或取消时保留诊断报告，不发布校正参数。若恢复失败，界面显示失败，应先检查连接，再回读/重新应用实际所需配置；不能把未恢复的测试状态视为正常测量状态。
