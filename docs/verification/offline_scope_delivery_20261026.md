## 当前交付

| 功能 | 实现与边界 |
|---|---|
| FPGA 基础测量 | 对同一冻结 16384 点记录计算最大/最小/均值、Vpp、RMS、频率、周期、占空比；无有效周期时返回无效标志。 |
| FPGA 1024 点 FFT | 周期 Hann 窗，返回主交流谱峰及 H2～H5 摘要；PC 曲线和板端摘要各自标明数据来源。25 MSPS 下间隔 24.4140625 kHz，低频精细测频沿用整帧时域方法。 |
| 零点、增益相对校准 | PC 调度 DDS/ADC 完整帧采集，三帧零点、九点直流拟合、四档幅度检查；首次运行建立组合链路相对参考，以后与保存的实测基线比较。 |
| 基本扫频 | 10、25、50、100、250、500、1000 kHz 七点，归一到本次 100 kHz 响应；演示采用相同频点。保留噪声 RMS 及主要谐波幅度。 |
| 校准前后对比 | 独立零点复测和未参与拟合的 +512 DAC 码点，显示相对目标及校准前后误差。两列使用同一原始观测，校正只改变显示换算。真实结果写入 `report.json` 的 `before_after`。 |
| 多分辨率采集 | 保留 FPGA min/max 包络、单帧 ROI、64 位时间戳与 PC 历史快照。板端每次只冻结一帧；UART 分包属于数据传输，不是多触发硬件分段采集。 |

取消演示自检会丢弃未完成参数。开始新自检或切换数据源会清除当前对比，避免把演示结果当成硬件结果。实物流程仍在成功、失败或取消后恢复并逐字节回读核对原 DDS/触发配置；只有成功并恢复后才允许应用校正。原始 ADC 码和 OTR 始终保留。

## 离线入口

双击工程根目录的 [启动离线演示.cmd](../../启动离线演示.cmd)，点击“运行演示自检”。也可执行：

```powershell
.\.venv-ui\Scripts\python.exe PC/ui/launch_scope.py --offline --calibration
```

页面包含七步进度、校准前后误差表和七点频响；小窗口下滚动页面查看下方内容。[演示截图](offline_scope_20261026/calibration.png) 和 [软件演示数值](offline_scope_20261026/software_demo_comparison.json) 均明确标为软件数据，不能作为实物测试结果。
