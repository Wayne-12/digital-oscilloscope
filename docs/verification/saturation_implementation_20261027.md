## 统计口径

- 饱和样本：原始 12 位 ADC 码等于 0 或 4095；每点最多记一次，不由 OTR 位或已下载 ROI 推断。
- 连续事件：同一线性冻结帧内的最大连续饱和区间。帧首与帧尾不相连；读取握手停顿不切断连续区间。
- 统计覆盖该冻结帧全部 16384 点，每帧清零，范围分别为 0～16384 个样本、0～8192 个连续事件（全饱和为一个事件）。计数在 FPGA 完整帧基础测量扫描时完成，结果冻结，随帧身份传输。
- UI 显示“整帧饱和样本 N / 16384、连续事件 E”，移除 OTR 报警及当前 ROI 点数。ROI 浏览、原始码、原始 OTR 位和数据有效性检查保留；部分窗口不能冒充整帧计数。旧固件仅有完整原始帧时可标注 PC 完整帧统计，只有局部窗口时显示未提供整帧计数。

## 协议

候选固件 `0xA2261027`、能力 31（新增 bit 4）、25 MSPS、16384 点、921600 bit/s。

`READ_SATURATION 0x34` 空请求，响应 0xB4 的 16 字节 `<BBHIII>`：版本 1、flags、零保留字、整帧点数、饱和样本数、连续事件数。flags bit0=有效，bit1=板内诊断帧。帧头时间戳、采样率和触发位置必须与该冻结帧一致；释放之前重复读取保持不变。

`SET_DIAGNOSTIC 0x14` 一个字节，需 STOP 后设置；0=真实 ADC，1=按时间戳 mod16 在 0/1/2/15 相位注入 raw0、7 相位注入 raw4095、其他为 raw2047，2=全 raw4095，3=全 raw2047。仅替换捕获存储器输入，DAC 引脚和 ADC 模拟输入不变。每个注入帧明确标记诊断，RESET 和 STOP 清除诊断模式；用户 UI 不提供诊断启用入口。
