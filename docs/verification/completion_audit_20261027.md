## 影响最终验收的发现

1. **模拟链路条件与旧基线显著不同。** 本次实测直流增益约+0.028814 ADC码/DAC码，相对旧基线0.258081倍，即下降74.192%。拟合R²约0.999988，四档幅度单调，表明当前相对校准流程可工作；不能据此证明绝对电压精度。独立零点误差约+6.692→−0.667 mV，独立直流验证误差约−97.264→−2.182 mV，这些电压基于项目标称换算与组合链路相对参考。应固定并记录旋钮、接线、供电及预热条件，再以外部参考验证/建立基线；本轮没有断言增益变化由某一部件造成。
2. **旧系统级回归入口无法运行当前设计。** `run_system_regression.py --system-only --seeds 20261027` 在CASE 0展开失败：`tb_system_case.sv:27` 的 `scope_protocol_core dut(.*)` 缺少新增 `awg_play_index` 信号。8个系统场景均未执行，不能称整套系统仿真通过。源码核查属于测试台接口不同步，未据此判定板端硬件故障；未修改产品RTL或旧测试断言。证据 `../../FPGA/reports/system/20261027_171618_1f2574b1/manifest.json`。
3. **FFT离线仿真未取得本轮PASS。** XSim 2025.2的9类独立单元通过（安全、ADC、DDS、触发、BRAM、测量、UART PHY、协议、包络），同一随机种子20261027。FFT最初在Tcl应用加载/IP生成失败；沿用项目已有Tcl仓库设置并使用既有R盘英文短路径后，IP生成通过，但在 `tb_spectrum_isqrt` 展开时出现 `XSIM 43-3409`（生成C文件编译失败）。因此整体单元回归清单为FAIL，不可写成10类全通过。环境诊断脚本报告0项硬失败，并不能排除该具体故障。原始与最后尝试见 `../../FPGA/reports/unit/20261027_171451_241040/manifest.json` 和 `../../FPGA/reports/unit/20261027_172319_053945/manifest.json`。本轮实物FFT对照通过，与离线仿真未通过分别记账。
4. **正式UART验收已完成，适用固件为0xA0261026。** 已核对原始报告：2026-10-26 21:05:56至23:15:58，COM12/921600 bit/s，回显600.0288608秒、13,418,616字节；长稳7200.2697149秒、32,961帧，含恢复检查共32,963帧；CRC、超时、序号错误、不完整捕获、FPGA错误新增及OTR均为0，停止重启、重新连接及原配置恢复通过，verdict=PASS。此项应计入项目已完成验收，不能描述成项目从未进行正式长稳。原始证据见 `../../releases/scope_20261026_uart_smoke_v1/PC/acceptance_runs/20261026_210556_574002_soak/report.json`。其固件SHA256为 `e69221cabb545f2de1bee2b12d8493a1ad43083c7928a519f45ac4312fb1ea0d`，与当前0xA4261027不同；当前升级镜像尚未补充同等正式测试证据，其他波特率也不据此取得资格。本轮14秒连续采集仅是当前镜像短测。
