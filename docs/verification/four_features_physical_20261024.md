# 四个页面的实物功能检查（2026-10-24）

结论：当前连接与当前固件下，时域波形、PC FFT 频谱、PC 多分辨率包络/ROI/历史记录可用；实物自动闭环自检与校准尚未实现，不能判定为四项全部可用。

## 实测条件与证据

- 时间：2026-10-24 20:19，Asia/Shanghai。
- 真实 USB 串口 COM12，FTDI VID:PID=0403:6010，921600 bit/s。
- 固件版本响应 `0100000024102620`；设备返回 25 MSPS、16384 点、预触发索引 8192。
- 通过正式 `SerialWorker`、协议编码/解析及波形重组路径，重新取得 18 帧完整记录及 2 帧 1505 点短窗口；每帧时间戳不同。未使用演示波形作为采集输入。
- 验证入口：`tmp/verify_four_features.py`。最终证据目录：`tmp/four-features-20261024_201930/`；其中 `verification.json` 为结构化结果，`raw_full_frames.npy` 保存 18 帧只读原始码的副本，四个 PNG 为正式窗口类显示本次真实采样的离屏渲染。界面另已通过原生窗口操作连接并执行 SINGLE，观察到真实波形与 FFT。
- 此前 `tmp/four-features-20261024_201831/` 为首次同组实测，结果同样通过；最终目录修正了验证窗口的串口选择显示与快照计数。

## 逐项结果

| 页面 | 结果 | 已验证内容与范围 |
| --- | --- | --- |
| 时域波形 | 通过 | 18 次完整独立采集，原始码只读；绘图数据逐点等于实际 ADC 电压换算值；测量频率约 99.989～100.011 kHz，Vpp 约 134.3～139.2 mV；全部 OTR=0。完整帧采集耗时中位数约 415 ms。 |
| FFT 频谱 | 通过 | 1024/2048 点分别搭配 Hann/矩形窗，共四种组合；绘图结果与正式计算函数一致，主峰均为 97.65625 kHz，与约 100 kHz 的时域测频相差小于一个频率格。 |
| 多分辨率采集 | PC 功能通过 | 16384 点压缩为 800 列 min/max，逐列对照原始数据完全一致；首部、中部、触发附近、末部四段 ROI 的横坐标及样本均逐点一致；保留最近 16 帧，选择旧帧冻结、切回最新帧通过。 |
| 闭环自检与校准 | 实物功能未实现 | 两种实物数据源均由 `source_changed()` 禁用“运行演示自检”和校准应用；硬件模式直接调用 `start_calibration()` 也立即返回，未启动定时器、生成参数或修改原始码。当前协议没有自动自检/校准命令。 |

FFT 的 1024 点频率间隔为 24.4140625 kHz，2048 点为 12.20703125 kHz，因此主峰显示 97.7 kHz 并不表示输入频率错误。当前采样不满足严格的相干/分辨率条件，四种组合的 THD 均显示“—”，没有将其报告成有效器件失真。

当时 FFT、包络、ROI 和历史帧在 PC 运行；该检查不能证明 FPGA FFT、板端分段或板端多分辨率已经完成。后续实现状态以各功能实物报告为准。

本次是现有约 100 kHz 信号、现有模拟接线下的功能检查，不是全频段/全幅度的计量校准。电压使用现有标称换算；没有据此宣称绝对幅度准确度或全范围性能通过。

## 通信与恢复

PC 的 CRC、长度、版本、超时解析错误均为 0；FPGA 前八项协议/UART 错误计数增量均为 0，采集后端错误为 0。

测试只发送 PING、GET_VERSION、GET_STATUS、STOP、SET_TRIGGER、SINGLE、READ_WAVE；未发送 SET_DDS 或 SET_RECORD，未烧录 FPGA、修改 Flash 或改变模块供电。独立串口检查结束后发送 STOP、恢复已保存的普通触发配置并释放串口；现有界面重新连接时按原实物联动模式应用其自动快照触发。

未改动产品源码、固件及硬件参数档。本次新增验证脚本、报告与证据文件。

现有可见界面已恢复 COM12 / 921600 的实物联动连接，执行新一次 SINGLE 后停在时域页，使用 Autoscale 调整到可读比例并保持 STOP 冻结。用户可直接点击 RUN 继续观察实物。
