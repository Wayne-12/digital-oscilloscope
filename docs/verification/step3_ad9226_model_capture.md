## 数值与故障模型

模型输入 `ideal_sample` 是 **32 位有符号整数 ADC LSB**，表示与项目输出同方向的理想样本；不输入真实模拟电压，也不直接解释为 mV。

模型顺序为：Q16 增益 → 整数舍入 → 直流偏置 → 噪声 → 过量程判断 → 饱和 → 反相编码 → 可选缺码映射。全部中间运算显式使用 64 位有符号数。

- `GAIN_Q16`：32 位有符号、16 位小数，默认 65536，即增益 1；仅接受非负增益。
- 舍入：最接近整数，恰好半 LSB 时远离零，例如 1.5→2、−1.5→−2。
- `OFFSET_LSB`：32 位有符号整数偏置，默认 0。
- `NOISE_LSB`：默认 0，支持 0～4096，注入 `[-N,+N]` 内的整数噪声。使用显式 32 位 xorshift 状态和确定种子，复位重建噪声序列，零种子映射为 1。
- 饱和区间：−2048～2047。变换后的输入严格越过端点才自动产生 OTR，端点本身不过量程。
- 反相原始码：`raw_code = 2047 - clipped_sample`。
- `MISSING_CODE_ENABLE/CODE/REPLACEMENT`：将某个原始码映射到另一码，模拟缺少码箱；不删除时间样本。
- `force_otr_enable/value`：在输入采样时覆盖本样本的 OTR，支持强制高和强制低；与数据经过相同流水线及输出延迟。

默认理想编码如下；这是项目已冻结的模块极性约定，包含模块模拟前端的反相含义。

| 理想样本 | 原始码 | RTL 有符号码 | 自动 OTR |
|---:|---:|---:|---:|
| −2049 | 4095 | −2048 | 1 |
| −2048 | 4095 | −2048 | 0 |
| −1 | 2048 | −1 | 0 |
| 0 | 2047 | 0 | 0 |
| 1 | 2046 | 1 | 0 |
| 2047 | 0 | 2047 | 0 |
| 2048 | 0 | 2047 | 1 |

RTL 解码固定为公共包的 `13'sd2047 - $signed({1'b0, raw_code})`。先零扩展原始码，再显式转为有符号数；原始 12 位不被解码结果替换。模型的参数检查 `initial` 只验证配置，流水线、有效位和噪声状态均通过明确复位初始化。

## 时序与复位约定

根据 [AD9226 Rev.B 数据手册第 3 页的开关规格和时序图](https://www.analog.com/media/en/technical-documentation/data-sheets/ad9226.pdf)，本模型采用 7 周期流水线及可配置的 3.5～7 ns 输出延迟。所有手写 SV 时间单位/精度为 `1ns/1ps`。

| 时点 | 动作 |
|---|---|
| ADC 上升沿 n | 锁存理想输入及本样本的 OTR 覆盖控制 |
| ADC 上升沿 n+7 后 `T_CO_NS` | 更新该样本的 `raw_code`、OTR 和模型观察用有效标志 |
| 内部采样上升沿 n+8 | `adc_capture` 读取上一拍已稳定总线，寄存原始码和 OTR |
| n+8 的 NBA 更新后 | `sample_valid`、`sample_raw`、`sample_otr`、`sample_timestamp=n` 可用；组合解码输出 `sample_signed` |

这里统计七个**完整周期**，不把进入流水线的那一沿算作第一个已过去的周期。采集 RTL 不在模型输出更新的时刻取数，也不增加有符号解码寄存器带来的额外一拍。后级消费者自己的寄存器延迟不计入本步的 7+1。

模型 `rst` 是仿真流水线清空控制，并非 AD9226 的物理管脚；它在 ADC 上升沿同步作用，外部输出复位值也经过配置的 T_CO 延迟。`output_valid` 只供模型验证，采集 RTL 不依赖这个不存在于实物上的有效引脚。

`adc_capture.rst` 为高有效同步复位，清零有效标志、OTR、计数器及时间戳，原始码置为 2047、有符号码为 0。新复位纪元前八个采样沿无有效输出；后续在 `capture_enable=1` 时每拍输出一个样本。无效周期保持载荷，重新使能后继续采集当前 ADC 总线，不停 ADC，也不重放旧样本。

时间戳是从本地复位纪元起的 **64 位原采样序号**：自由运行边沿计数减去显式 8 周期延迟，按无符号 64 位模运算回卷；预热计数独立饱和，避免计数器回卷后再次产生预热间隙。

八拍只是本前端的有效流水线保护，不能替代第二步的 ADC 启动/换频后 256 周期稳定等待。系统集成时仍应使用安全状态机的 `capture_enable`。本模块是不能反压的 ADC 源，未连接 `sample_ready`；后续应通过 FIFO 适配统一 ready/valid 流。
