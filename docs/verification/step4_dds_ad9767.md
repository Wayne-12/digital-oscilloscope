# 第四步：DDS 与 AD9767 A 通道行为模型

本步仅验收 RTL 行为与数字接口时序。工具为 Vivado/XSim 2025.2，临时器件 xc7a35tcsg324-1；未添加开发板预设、完整 EGO1 XDC 或最终管脚约束。

## 文件与接口

- `FPGA/rtl/dac_dds/dds_core.sv`：32 位相位累加器、四种波形、数字幅度、相位偏移与饱和。
- `FPGA/rtl/dac_dds/dds_sine_lut.sv`：1024 点完整周期有符号 ROM，以静态 case 表表达，不依赖寄存器初值或外部初始化文件。
- `FPGA/rtl/common/scope_pkg.sv`：新增 `dds_wave_t`、32 位相位宽度、1024 点表长及默认 DAC 采样率 25 MHz。
- `FPGA/sim/models/ad9767_model.sv`：双端口模式 A 通道双缓冲及接口断言；仿真专用。
- `FPGA/sim/tb/dds_scenario.sv`、`dds_safe_scenario.sv`、`tb_dds.sv`、`tb_ad9767_fault.sv`：正向、自检、安全联动与故障注入。
- `FPGA/scripts/generate_dds_vectors.py`、`audit_dds_traces.py`、`run_dds_tb.ps1`、`check_dds_project.tcl`：独立黄金数据、轨迹复核、回归与原生工程仿真。

所有手写 HDL 时间单位与精度为 `1ns/1ps`，采用 `default_nettype none`。RTL 只使用输入时钟的下降沿，没有组合逻辑产生的内部时钟。

## DDS 数值约定

| 输入/输出 | 类型与含义 |
|---|---|
| `clk_dac` | 外部提供的 DAC 时钟；DDS 在下降沿更新数据，供下一上升沿使用 |
| `rst` | 高有效同步复位，在下降沿生效 |
| `enable` | 低时同步输出 8192，清除相位累加器和启动状态 |
| `waveform` | `DDS_SINE=0`、`DDS_SQUARE=1`、`DDS_TRIANGLE=2`、`DDS_DC=3` |
| `phase_inc` | 32 位无符号频率控制字，按模 2^32 累加 |
| `phase_offset` | 32 位无符号相位偏移，1/4 周期为 `0x40000000` |
| `amplitude` | 16 位无符号峰值幅度，单位 DAC LSB，允许超过满量程以测试饱和 |
| `dc_offset` | 18 位有符号偏移，范围 -131072..131071，单位 DAC LSB，相对于 8192 |
| `dac_code` | 14 位无符号输出，范围 0..16383 |
| `sample_phase` | 当前输出波形对应的完整 32 位相位，便于追踪 |
| `sample_valid` | 首次中码呈现时为 0，随后连续为 1；这是波形有效标记，不是 DAC 的写使能 |

有效相位为 `(accumulator + phase_offset) mod 2^32`。正弦表以相位最高 10 位寻址，系数为 `round(32767*sin(2*pi*i/1024))`，范围 -32767..32767。方波前半周期为 +32767，后半周期为 -32767。三角波在相同 1024 点相位网格上按 0、+32767、0、-32767、0 变化；DC 的交流系数为 0。

乘法、偏置和饱和前中间值均为显式 64 位有符号数。系数乘幅度后除以 32767，取最近整数，恰好半数时远离零。三角波系数除以 256 采用相同舍入规则。最终输出为 `clamp(8192 + dc_offset + scaled_wave, 0, 16383)`，饱和后才截取 14 位，不允许无符号绕回。

使能后的第一个下降沿固定呈现 8192，不使用配置波形；下一个下降沿输出相位 `phase_offset` 对应的波形并推进相位。复位/停用均重新开始这一过程。控制输入须由同一时钟域提供，并在下降沿前稳定；跨域寄存器与命令原子更新留待后续控制接口集成。

频率控制字在控制端计算：`phase_inc = floor(f_out * 2^32 / f_dac + 0.5)`。在无混叠范围，控制字量化误差上限为 `f_dac / 2^33`。相位地址截断和幅度量化会影响波形采样值及短窗口均值，黄金模型包含这些影响。

## AD9767 锁存与时序

模型按用户指定的 ACLK/WR1 同相接口建模。WRT 上升沿锁存 DA，ACLK 同时将**上一拍输入锁存器**传入 DAC 锁存器；两个功能寄存器使用非阻塞赋值，保留一拍额外缓冲。输入首码和首个有效 DAC 输出均断言为 8192。该关系依据 [Analog Devices AD9763/AD9765/AD9767 Rev. G，第 24 页双端口时序](https://www.analog.com/media/en/technical-documentation/data-sheets/ad9763_9765_9767.pdf)。

模型断言检查建立时间至少 2.0 ns、保持时间至少 1.5 ns、ACLK/WR1 同相，以及 BCLK/WR2 恒为已知 0。相位比较允许同一仿真时刻的 delta-cycle 传播，在 1 ps 后检查，任何至少 1 ps 的偏差均可检出。模型针对本项目同相模式，不支持芯片的其他 CLK/WRT 相位模式。

`rst` 和 `bus_enable` 是验证抽象接口：复位或总线关闭时异步清空模型锁存有效位，为下次会话检查首码。它们不表示 AD9767 具有相同的硬件复位引脚。监视器的时间戳/统计初值仅用于仿真检查，不代替 RTL 功能复位。模型不计算模拟电流、模拟建立时间、INL/DNL 或输出滤波。

## 测试与黄金模型

Python 黄金模型不读取 RTL ROM 或调用 DUT 函数，使用独立整数计算和数学正弦生成每拍期望值。测试对每拍同时核对 DAC 码、完整相位、波形有效位、输入锁存器及上一拍 DAC 锁存器。

18 个用例在 10/25/50/65 MHz 四档时钟上运行：中码/正负偏置直流，1 kHz/10 kHz/100 kHz/1 MHz 正弦，整周期正弦/方波/三角波，双端饱和与偏置极限、相位偏移、零幅度、Nyquist 方波、最大控制字绕回、12000 拍随机配置与中途复位/停用。随机用例前缀专门检查幅度 8190/8191/8192/8193 的正负半周以及直流偏置两端极限，结果分别包含 16382/16383/16383/16383 和 2/1/0/0，证明满量程附近按饱和处理。四个命名正弦频率以 25 MHz 为基准，其他时钟使用相同控制字，目标频率按时钟比缩放。

每个时钟档每种子核对 151932 拍。独立 CSV 审计检查完整计数、码值范围、最小/最大值、总和/均值、相位回绕及波形上穿中码的周期；整周期正弦/方波/三角波均值精确为 8192。短窗正弦均值与黄金采样结果逐码一致，不强制不相干窗口均值恰好为中码。

频率验收区分两类误差：控制字理论频率按 32 位公式核对半 LSB 上限；有限窗口从实际波形上穿点测周期，允许相邻周期与理论采样周期相差不超过 1.01 个样本。后者不能声称验证到毫赫兹的模拟频率精度。65 MHz 理想时钟受 1 ps 精度量化，实际周期 15384 ps，CSV 审计从仿真时间测出实际时钟，并单列量化后频率。

安全联动使用第二步真实 `scope_core` 控制 DDS 和独立引脚三态模型：完整启动 24 次，撤销使能 17 次，复位与失锁各 6 次，包含五个启动/RUN 阶段撤销。复位/失锁后检查引脚 Z，有序停机在限定周期内回到 SAFE_HIZ，DAC 开始驱动时首码 8192。原有安全回归另行复跑。

另有 5 个负向测试，分别故意破坏建立、保持、ACLK/WR1 相位、B 通道零状态和安全首码。每项必须触发指定断言；其预期 Fatal 只出现在 `fault_*.console.log`，与正向回归的零断言失败分开判定。

## 重跑

```powershell
& 'D:\示波器\FPGA\scripts\run_dds_tb.ps1' -Project
# 自选可复现种子，仍执行首种子重放：
& 'D:\示波器\FPGA\scripts\run_dds_tb.ps1' -Seeds 123,456 -Project
```

默认种子为 20261020、42。每次在新的 ASCII TEMP 目录从源文件编译；原始向量、期望数据分别留在 `sim/vectors/dds/<run>/` 与 `sim/expected/dds/<run>/`。报告保存编译/展开/运行日志、命令、种子、源码 SHA256、逐拍 CSV、统计审计和重放哈希比较。原生项目仍使用 Vivado Simulator，仿真顶层设为 `tb_dds`，设计顶层保留 `scope_hw_top`；模型和 TB 只在 Simulation Sources 中。

原生工程模式在本机需要正常写入用户 AppData 的 TclStore；受限启动若出现 `Common 17-356` / `load_features`，应在有该目录权限的环境运行相同脚本，不改用其他仿真器。原生项目 CSV 在 XSim 工作目录用相对路径写出，再由 Tcl 归档。

本步未把 DDS 配置端口接入 `scope_hw_top` 的板级顶层；该顶层仍保留第二步固定中码的安全验证接口。DDS 已通过真实安全控制器与引脚行为模型联动验收，后续顶层集成时再连接配置、Clock Wizard/ODDR 和管脚。本步结果不等于已完成布局布线时序或实板模拟输出验收。
