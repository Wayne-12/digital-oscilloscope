## 后续写报告时的操作

1. 根据最终报告章节检索，优先筛选与实际实现相关的期刊和学位论文；基础方法可引用较早的原始文献。
2. 打开原始题录，核对标题、作者、年份、刊名或授予单位、卷期页码、DOI及知网详情链接。搜索摘要或搜索引擎片段只作为线索。
3. 对拟支持技术结论的文献阅读正文，记录对应页码、方法及适用条件。只有摘要时标为“仅核验题录/摘要”，不声称读过全文。
4. 保存官方导出的引用文本或 BibTeX（以页面实际提供的格式为准），全文获得合法访问权限后存入本目录下的 references/。
5. 建立文献台账，字段为：编号、标题、作者、来源、年份、卷期页码、DOI、详情链接、核验状态、正文证据页码、拟引用章节、本地文件。
6. 写作时按学校或竞赛的格式要求统一引用，交稿前逐条核对正文引用和文后条目；缺失字段标注待核验，不补造。

本项目的校准范围以《示波器项目规划书（终）》为准，属于零点与增益相对校准；选择文献和撰写结论时应保持这一边界。
