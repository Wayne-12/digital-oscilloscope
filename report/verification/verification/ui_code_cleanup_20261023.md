# 示波器 UI 代码清理记录

本次基于当前磁盘主程序进行增量清理，保持现有启动入口、界面功能、UART 帧格式及上一轮性能优化。

## 清理内容

- 删除未使用的 `MUTED` 常量。
- 删除已无调用方的普通队列 `stop` 分支；STOP 统一由独立事件处理，队列入口只接受 capture/status/command，非法任务立即拒绝。
- 合并 RUN、STOP、SINGLE 的共享状态切换与启动检查，使 `set_running(True/False)` 两条路径均有实际调用。
- 删除重复的波形序号赋值、重复解包和不再使用的命令提交返回值。
- 将样本保留位、采样率与触发索引范围统一交给不可变 `Capture` 校验；保留传输层的 CRC、分包顺序和请求范围校验。
- 调整 ROI 定时器的初始化顺序，删除不再需要的属性存在性兜底分支。
- 用字典字面量替代六处额外的 `dict()` 构造调用。
- 保留 Qt 线程入口、关闭事件、滚轮事件及防误触控件继承类；这些都有框架或正常界面的实际调用。
