## 显示与输入

1024×600，49 MHz 像素时钟，水平总长1312、垂直总长624，负极性同步。
EGO1 VGA 接有源 VGA→HDMI 转换器，再接显示器 HDMI。
这个时序沿用原1024×600工程，不能仅凭面板分辨率保证转换器接受，最终需实屏确认。
主界面中文为宋体24像素，英文和数字为Times New Roman 22像素；右侧单行测量栏采用宋体20像素、Times New Roman 18像素。
字形均按最终尺寸生成，右侧名称、数值和单位在同一行，不由大点阵缩放而来。
统一数字基线，负号使用数学减号。菜单参数行距48像素。

| 板上位置 | 标号 / FPGA引脚 | 操作 |
|---|---|---|
| 上 | S4 / U4 | 向上预选；编辑时粗调增加 |
| 下 | S1 / R17 | 向下预选；编辑时粗调减小 |
| 左 | S3 / V1 | 向左预选；编辑时微调减小 |
| 右 | S0 / R11 | 向右预选；编辑时微调增加 |
| 中心 | S2 / R15 | 进入页面、执行按钮或确认参数 |

映射依据为 EGO1 用户手册的板卡布局与按键引脚表；还需逐键实物确认。
方向键按屏幕上控件的位置移动。上移到页签后，左右预选页面，中心进入。
中心进入参数编辑后显示 `*`，调整数值仅改变草稿，再按中心才应用。
运行/暂停、单次和自动校准量程均通过屏幕按钮选择，无需功能拨码。
自动校准量程按钮宽288像素、高88像素，跨越两行刻度设置，文字在框内居中；它只自动选择时基和垂直刻度，不会重新标定电压。
SW0 仍用于外部模块安全使能，配置后须 OFF→ON；SW7 ON交给电脑控制，OFF回到本地。
本地应用参数时先关闭DDS、切回标准波形再应用输出设置，避免电脑此前选择的AWG波形继续播放。

## 页面

| 页面 | 功能 |
|---|---|
| 波形 | 运行、暂停、真实触发单次、五档时基、四档垂直刻度、自动量程、频率/Vpp/RMS/平均值 |
| 触发 | AUTO/NORMAL/SINGLE、九类触发、门限/迟滞/预触发；按类型显示窗口、脉宽或幅度相关参数 |
| 信号源 | 正弦/方波/三角/直流，输出开关、频率、相位、数字幅度、偏置，回环幅度旋钮图形 |
| 光标 | 两条时间光标和两条电压光标，时间差与电压差 |
| 频谱 | 原后端1024点Hann FFT的512个频点、主峰、H2～H5相对幅度；图形为对数功率显示 |
| 自检 | 确认接好 DAC OUTA→ADC IN 后发起1MHz正弦回环测试，检查频率、Vpp、饱和与OTR，结束/错误/超时恢复设置 |

波形区宽640像素、10个水平格，读数栏宽288像素；读数右对齐，数值与单位间隔一个字符。
时基为640、2560、10240、40960、65536 ns/div，每格64像素。
最慢档覆盖完整16384点记录，扩宽后仍维持正确的时间比例；FFT的512个频点也按640像素重新映射。
640 ns/div是对同一记录的4倍水平放大，相邻采样点之间按1/4步长线性插值，不提高25 MSPS采样率。
垂直刻度为2240、560、280、140 mV/div，每格40像素。
波形绘制保留1/16像素的垂直精度，并对线段边缘按覆盖率显示灰度，减少放大阶梯与像素锯齿。
插值只作用于绘图，不修改冻结记录、测量值或FFT，也不进行会削平尖峰的平滑滤波或产生过冲的曲线拟合。
非放大档仍为取点连线；最慢档没有保峰包络，窄脉冲需缩小时基检查。
真实单次在没有合格触发时保持等待，可选“取消单次”停止。

频率读数以kHz显示，最多保留3位小数并去掉末尾零；例如1000000Hz显示1000kHz。
FFT频率间隔约24.414kHz；低频读数以时域测频为准。
RMS包含直流分量。无效测量显示横线，不将无周期解释为0Hz。

## 实物幅度旋钮

AD9767模块手册明确说明旋钮是模拟增益电位器，通道A顺时针放大、逆时针衰减。
现有数字接口不提供旋钮位置或转角。
信号源页的圆形指针因此表示**ADC回环实测峰峰值**，按用户提供的108～2212mVpp映射到270度指针范围，端点之外钳位，不能当作真实机械角度。
映射参数位于`panel_knob_scale.h`，共361个位置、每步0.75度；1160mV对应中点。
该范围对应用户测量时的信号源设置；改变DDS数字幅度、波形或回环连接后，不能保证机械位置仍对应原来的指示角度。
信号源左侧名称、数值、单位分别从第5、22、32列开始，与波形页底部刻度设置使用相同间距。
旋钮采用统一灰蓝色表面、偏移投影与明暗斜边；刻度只覆盖指针起点到终点的270度，底部90度留空。
每5度一条刻度（含两端共55条），每45度加长突出，与108～2212mV的指针行程一致。
外圈为青蓝色，实心三角箭头比灰蓝色旋钮面略亮，保持柔和对比；下方以小字号同一行显示“回环峰峰值”、数值和mV。
三角箭头始终显示：未取得有效采样时停在起点；有效采样更新角度；暂停或测量无效时保持最后位置。
需要 DAC OUTA 接 ADC IN 并运行采集，旋转实物旋钮后才会随测得幅度更新；暂停时保持最后读数。
其他输入信号、DDS幅度改变也会使指针改变；没有回环时不能据此判断旋钮位置。

## 固定校正

`panel_calibration.svh` 使用根目录 `voltage_calibration.json` 的外部参考直流系数。
界面的“电压校正已应用”是自动校正的状态提示，不是可选按钮。
整帧16384点均在原码1637～2462内才应用，任何一点越界则整帧回退标称换算。
波形、Vpp、RMS、平均值使用相同的整帧选择。已测直流范围不构成交流或全量程精度保证。
触发设置仍采用原始码域；界面没有在板上重新标定或写入新校正的流程。

## 固化与上电

JP2保持QSPI。上电等待配置完成，再恢复ADC/DAC模块5V，并将SW0从OFF拨到ON；SW7 OFF使用本地按键。
`release/display_final.mcs`、`.bin`、`.bit`为当前最终固化镜像，`image_manifest.json`绑定最终JTAG位流、ELF和源快照。
`release/flash_record.json`记录编程、独立回读、Flash重新加载及真正断电启动结果。
`release/hardware_*/flash_before.bin`为本次写入前完整8MiB恢复备份，属于必要保留文件。

重建通过后可用 `run.ps1 -Action prepare_flash`生成SPI启动镜像。
确需重新固化时，先关闭模块5V、SW0 OFF，保持开发板/JTAG供电，再执行 `run.ps1 -Action program_flash`。
脚本保留JEDEC器件识别，先备份再编程校验、独立回读比较，并从Flash重新启动。
真正断电重上电后，`run.ps1 -Action verify_flash_boot`仅检查启动寄存器，不重新下载。
