# 2026-11-01 电脑界面优化

版本2026.11.01-r2，入口仍为根目录启动示波器界面.cmd。

- 自动量程按波形占据约六个垂直格选择刻度，并保留完整记录的上下余量。板端频率无效时，用当前原始记录独立估计频率选择时基。运行中点击自动量程会等待采集暂停、确认配置后继续运行，保留撤销功能，不改动采集原始码。
- FFT摘要改为有行距的表格排版；H2～H5分别占独立单元格，窄窗口每行两项，幅度换算说明独立成行。
- 闭环页移除顶部大段说明，简化相对校准状态及完成提示；接线提示放入自检按钮悬停信息，数据记录路径仍保存并可从结果提示和日志查看。
- 工具页的时间/电压光标增加整行矩形边框、清晰勾选框及悬停状态。移除实物测量与验收说明入口及过载验收说明文字。
- 连接成功时刷新为“STOP · 已连接”，避免保留先前的未连接状态文字。
