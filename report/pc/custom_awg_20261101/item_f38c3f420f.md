# 任意波形生成与实物测试

后续演示更新：根目录任意波形.csv已按用户要求替换为五电平阶梯波，当前说明与数据属于此前复合波。原复合波文件已保存为本目录`任意波形_复合波.csv`；当前演示设置见`PC/reports/demo_awg_20261101/现场演示说明.md`。

文件：项目根目录`任意波形.csv`，UTF-8、单列`value`，1024点、归一化范围[-1,1]。

波形为归一化的sin(θ)+0.35sin(2θ)+0.20sin(3θ)，首尾周期连续、均值为零；包含可辨认的肩部变化，适合演示任意波形输出。数字波形表CRC16为0DEE，下载后1024点逐点读回一致。

在最终CPU通信修复镜像、COM12 / 921600、OUTA→IN实际回环上测试：

| 设置频率 | 实测频率 | 数字峰值 | 实测与目标形状相关系数 |
|---|---|---|---|
| 10 kHz | 9.999 kHz | 819码 | 0.999780 |
| 100 kHz | 100.006 kHz | 819码 | 0.999767 |
| 500 kHz | 500.000 kHz | 819码 | 0.999773 |
| 100 kHz | 100.000 kHz | 1638码 | 0.999937 |

峰值翻倍时实测峰峰值约1.967倍。所有测试帧均无OTR、无饱和，协议错误计数无新增。UI实际执行下载CSV、读回校验、选择任意波形表、应用DDS、ADC采集与自动量程；100kHz、20%数字幅度下UI回环波形相关系数0.999937。

最初零迟滞的10kHz小幅度测频受噪声重复交越影响，读数偏高；增加至8 ADC码（约19.5mV）的迟滞后，三档频率读数均通过1%相对误差判据。初始报告与10kHz原始数据保留为report_initial.json、initial_10khz.npy；最终结果见report.json。

测试后原DDS、触发、采集模式和原有效表逐项读回确认恢复。当前表即本次生成的任意波形，已下载到易失RAM但未选作输出；CSV永久保存在电脑项目目录。未写入FPGA Flash。

## 使用

1. 保持SW7 ON并连接设备，在“输出”页点击“下载任意波形CSV…”，选择根目录`任意波形.csv`。
2. 波形选“任意波形表”，建议先设置100kHz、数字幅度10%～20%、偏移0、相位0，勾选输出并点击“应用DDS配置”。
3. 保持OUTA→IN连接，选择AUTO采集、RUN，再点Autoscale查看。低频小幅度信号建议触发迟滞至少20mV，避免噪声造成重复交越。

数字幅度是DAC比例，实际电压随实体幅度旋钮和连接条件变化。断电后需要重新下载CSV。
